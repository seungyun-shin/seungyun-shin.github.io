사이트 소개

근거 계산기은(는) 한국의 세금·노무 제도를 누구나 직접 계산해 볼 수 있도록 만든 무료 계산기 모음입니다. 정부 기관이나 특정 회사와 관계가 없는 개인 운영 사이트입니다.

운영자

  • 운영: 근거 계산기 운영자
  • 문의·오류 제보: GitHub Issues로 제보

계산 원칙

  1. 법령, 고시, 관계 기관의 공식 안내를 1차 근거로 씁니다. 각 계산기 하단과 요율·기준표에 출처를 적습니다.
  2. 원문으로 확인하지 못한 값은 '확인 필요'로 표시하고 숨기지 않습니다.
  3. 계산 로직은 공식 예시(고용노동부 퇴직금 계산 예시, 근로소득 간이세액표 원문 등)로 만든 자동 테스트를 통과해야 배포합니다.
  4. 요율이 바뀌면 시행일에 맞춰 반영하고, 페이지의 '최종 수정'과 '요율 점검' 날짜를 갱신합니다.

오류 제보

계산 결과가 실제와 다르다면 입력값(결과 링크 복사 버튼으로 복사한 주소)과 실제 금액을 GitHub Issues로 알려 주세요(페이지 아래 '오류 제보' 링크). 확인 후 수정하거나, 수정 전까지 해당 계산기에 안내를 붙입니다.

책임의 한계

이 사이트의 결과는 참고용 추정치입니다. 회사의 취업규칙, 개별 근로계약, 관계 기관의 판단에 따라 실제 금액은 달라질 수 있으며, 이 사이트는 노무·세무 자문이나 대리를 하지 않습니다. 중요한 결정 전에는 고용노동부(1350), 국세청(126), 국민연금공단(1355), 국민건강보험공단(1577-1000) 또는 공인노무사·세무사와 상담하세요.
